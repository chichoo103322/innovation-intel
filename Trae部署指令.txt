请帮我部署一个 Python 自动化项目。项目文件夹就在当前工作目录下的 `innovation-intel` 文件夹中。请严格按照以下步骤一步一步完成，每完成一步向我确认。

---

## 第1步：安装 Python 依赖

检查系统是否安装了 Python 3（运行 `python3 --version`），如果没有则引导我安装。
然后进入 `innovation-intel` 目录，执行：

```
pip3 install openai python-docx
```

---

## 第2步：确认 Chrome 浏览器已安装

项目使用 Chrome 无头模式做 HTML → PDF 渲染，需要系统已安装 Google Chrome。
运行以下命令确认：
- Mac: `ls "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`
- Windows: `dir "C:\Program Files\Google\Chrome\Application\chrome.exe"`

如果未安装，引导我去 https://www.google.com/chrome/ 下载安装。

---

## 第3步：帮我获取 DeepSeek API Key

1. 告诉我打开 https://platform.deepseek.com 注册账号
2. 注册后在「API Keys」页面创建一个新的 API Key
3. 让我把 API Key（sk- 开头的一串字符）发给你

收到我给的 Key 后，帮我设置环境变量或写入 `config/settings.yaml` 文件。

> 推荐使用环境变量：`export DEEPSEEK_API_KEY="sk-..."`

---

## 第4步：配置期号起始日期

请**问我**："你希望第一期从哪天开始？（比如 2026-07-07）我会按工作日自动计算后续期号。"

收到我的回答后，帮我把日期写入 `config/settings.yaml` 的 `first_issue_date` 字段。

---

## 第5步：配置桌面输出路径

在 `config/settings.yaml` 中，找到 `desktop_output_dir`，根据当前系统改成正确的路径：

- Windows：`C:/Users/我的用户名/Desktop/创新情报`
- Mac：`/Users/我的用户名/Desktop/创新情报`

报告会自动存入子目录：`日报/` `周报/` `月报/`

---

## 第6步：安装定时任务

### Mac（终端执行）：
```
bash innovation-intel/scripts/setup_scheduler.sh
```

### Windows（以管理员身份运行 PowerShell）：
```
powershell -ExecutionPolicy Bypass -File innovation-intel/scripts/setup_scheduler.ps1
```

安装后确认定时任务：
- 日报：每 30 分钟自动检测（工作日生成，已生成则跳过）
- 周报：每周五 17:00
- 月报：每月最后一天 17:00

---

## 第7步：测试运行

执行一次完整日报生成（联网搜索 → 分析 → HTML → PDF → 桌面分发）：

```

```

测试周报：
```

```

测试月报：
```

```

等待 1-3 分钟，检查：
1. 终端输出显示「搜索→去重→生成→分发」全流程完成
2. 桌面「创新情报」文件夹下对应子目录有 PDF 文件
3. 打开 PDF 检查封面、蓝色小标题、排版是否正常

---

## 第8步：删除测试文件

确认无误后，删除测试生成的 PDF 和 HTML 文件（`daily/` `weekly/` `monthly/` 目录下），避免明天正式运行时被去重机制跳过。

---

## 第9步：校验与核查（⚠️ 重要）

每次生成报告后，系统会自动运行两道质量关卡：

**关卡1：后处理校验**（`scripts/validate_report.py`）
自动检查8个维度：
1. 机构名称准确性（"科技委"≠"科委"，写错属于政治性错误）
2. 常见错误名称纠正（"G60科技走廊"→"G60科创走廊"等）
3. 信源权威性（.gov.cn 域名占比，每条必须有可追溯的 URL）
4. 🔴 日期交叉比对（报告日期必须=正文事件日期，严禁=网页发布日期）
5. 数据精度（金额/百分比格式校验）
6. 禁用词扫描（"值得借鉴""有参考价值"等空话套话）
7. 创新洞察深度（字数+必含关键词维度）
8. 板块完整性（每板块至少1条 .gov.cn 来源）

**关卡2：事实核查**（`scripts/fact_check.py`）
- 标题与爬虫采集素材交叉比对
- URL 可追溯性验证
- 禁用词二次扫描

> 发现错误（error）会打印到终端，发现警告（warning）建议人工复核。
> 校验日志保存在 `cache/validation_log.txt`。

---

## ⚠️ 最高频错误警示（交付前必查）

1. 🔴 **日期**：报告日期字段只能填正文中事件实际发生日期，严禁填网页发布日期。爬虫素材中区分"事件日期"与"网页发布"两个字段，AI 提示词已强制要求只取事件日期。
2. 🔴 **机构名**："科技委"是党委议事协调机构，全称"中国共产党XX省/市委科技委员会"，不是政府部门的"科委"。写错属于政治性错误。
3. 🔴 **禁用词**：禁止出现"值得借鉴""有参考价值""值得关注""意义重大""影响深远"等空话套话，必须替换为具体可操作的分析和建议。
4. 🔴 **信源追溯**：每条信息必须有可访问的原文 URL，无 URL 视为未经验证，校验层直接报错拦截。
5. 🔴 **禁止编造**：所有信息必须基于爬虫真实采集的素材生成，不得凭空编造任何事实性内容（日期、金额、政策名称、会议名称等）。

## 项目结构

```
innovation-intel/
├── run_daily.py                  # 日报主入口
├── run_weekly.py                 # 周报主入口
├── run_monthly.py                # 月报主入口
├── config/
│   ├── settings.yaml             # 配置文件
│   └── daily_prompt.md           # 日报 AI 提示词规范
├── scripts/
│   ├── generate_html_pdf.py      # HTML→PDF 生成（日报/周报/月报共用，含AI提示词）
│   ├── validate_report.py        # 后处理校验（8维度自动检查）
│   ├── fact_check.py             # 事实核查（标题/URL与爬虫素材交叉比对）
│   ├── crawler.py                # 信源爬虫（24个.gov.cn权威信源）
│   ├── generate_docx.py          # Word 生成（辅助）
│   ├── generate_pdf.py           # fpdf2 备用方案
│   ├── dedup.py                  # 去重模块
│   ├── distribute.py             # 桌面分发模块
│   ├── setup_scheduler.sh        # Mac 定时任务安装
│   └── setup_scheduler.ps1       # Windows 定时任务安装
├── daily/                        # 日报输出
├── weekly/                       # 周报输出
├── monthly/                      # 月报输出
└── cache/                        # 缓存 & 日志
```

---

以上全部完成后，系统就部署好了。之后每天自动运行，只需去桌面「创新情报」文件夹查看 PDF 报告即可。
