⛔ 第0层 · JSON 格式红线（最高优先级，不可逾越）
═══════════════════════════════════════════════════════════

🔴 **必须使用 Python `json.dump()` 构建 JSON 文件，禁止手工拼接 JSON 字符串。**

历史事故：手工编写的 JSON 文件中，中文引号内容（如「"20+8"」「"给政策"」）使用的 ASCII 双引号 `"` (U+0022) 会与 JSON 结构引号冲突，导致解析失败，每次都需要反复修补。

**强制规则：**
1. 构建 JSON 时，将所有内容写成 Python dict/list，内部引用一律使用直角引号 `「」` (U+300C/U+300D) 替代中文双引号
2. 使用 `json.dump(data, f, ensure_ascii=False, indent=2)` 写入文件
3. 写入后立即运行 `python3 -m json.tool weekly/report_weekly_YYYYMMDD.json > /dev/null` 验证
4. 严禁在 JSON 字符串值内出现 ASCII `"` (U+0022)；若必须出现，用 `「」` 替代

**错误示例（会导致 JSON 解析失败）：**
```json
{"summary": "深圳发布"20+8"产业集群3.0版"}  ← "20+8" 中的 " 与 JSON 分隔符冲突！
```

**正确示例：**
```python
data = {"summary": "深圳发布「20+8」产业集群3.0版"}  # 使用直角引号
json.dump(data, f, ensure_ascii=False, indent=2)
```

每条政策只写**1条深度洞察**（150-250字），必须包含：

1. **产业赛道锚定** —— 五大产业至少1个，点出具体技术/产品方向

- "值得借鉴""有参考价值""值得关注""值得学习""值得研究"
- "应该加强""应该重视""建议重视""意义重大""影响深远"

- 照搬原文不做本地化转化
